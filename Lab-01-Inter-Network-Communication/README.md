# Lab 01 – Inter-Network Communication Using a Router

## Objective
The objective of this lab was to enable communication between devices located on different IP networks using a router.

## Network Topology
- 1 Router
- 2 Switches
- 4 PCs

## Configurations Performed
- Configured router interfaces
- Assigned IP addresses to end devices
- Configured default gateways
- Verified connectivity using ping

## Verification
- Successful communication between different networks

## What I Learned
- Routers enable communication between networks
- Proper IP addressing is essential
